# Changelog

## 1.0.0 (24 November 2026)

First public release, accompanying the article submitted to The BMJ (Analysis): "Fixed spending targets and outbreak preparedness in US bilateral health agreements".

- One script (`run_all.R`) reproduces every estimate, table and figure from the analysis-ready data in `data/analysis/`; `--rebuild-data` first rebuilds that data from the original downloads.
- `data/paper_numbers.csv` lists each number in the article with the result it comes from; the run checks all 57 computed numbers.
- Figure 1 marks Kenya and Nigeria, which reported imported Ebola cases in October 2026.
- Results are identical to the authors' internal version 5.0.0 (23 November 2026).
